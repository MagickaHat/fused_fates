Optional art for the character editor (see EDITOR_LAYOUT, UI_FOLDER and UI_GRAPHICS in
Plugins/[Fused Fates] Character Customization System/000_Settings.rb).

Each file is stretched over its area. Any file that is missing is replaced by flat colors,
so the editor works without art.

  bg.png       - whole screen, drawn behind everything (512x384)
  header.png   - title/money bar above the preview (288x32, only shown in titled or paid sessions)
  preview.png  - area behind the player preview (288x240 with a header, 288x272 without)
  info.png     - info panel under the preview (288x112)

The command list on the left uses the current windowskin.

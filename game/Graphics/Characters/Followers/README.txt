Following Pokémon sprites (normal colours)

This folder belongs to the following Pokémon plugin (e.g. Following Pokemon EX).
Put one 4x4 charset per species here, named like the battle sprites
(SPECIES.png, SPECIES_form.png, ...). The fusion system splices fusion followers
from these files, so a fusion only gets a spliced follower when both its head and
body have a sprite here.

Custom fusion followers go in the Fusions subfolder.

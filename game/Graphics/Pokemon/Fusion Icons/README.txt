Custom fusion party/PC icons (Fused Fates Fusion System)

Any fusion without a file here gets an icon stitched from its head and body icons.

File names:  HEAD[_form]_BODY[_form][_shiny].png
Examples:    PIKACHU_CHARMANDER.png
             PIKACHU_CHARMANDER_shiny.png

Icons use the same layout as Graphics/Pokemon/Icons: square frames placed side by
side (usually 2 frames, 128x64).

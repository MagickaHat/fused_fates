Custom fusion battle sprites (Fused Fates Fusion System)

Any fusion without a file here gets a sprite stitched from its head and body.

File names:  HEAD[_form]_BODY[_form][_back][_shiny].png
Examples:    PIKACHU_CHARMANDER.png
             PIKACHU_CHARMANDER_back.png
             PIKACHU_CHARMANDER_shiny.png
             RATTATA_1_GEODUDE.png         (Alolan Rattata head)
             PIKACHU_CHARMANDER_back_shiny.png

Forms are only written when they are above 0. The suffix order is _back, then _shiny.
After adding files while the game is running, use Debug > Pokémon options >
"Clear fusion sprite cache".

# Contest effects. Every move in contest_moves.txt has one (its Effect).
#   Name        - short name, shown on the summary's CONTEST MOVES page
#   Description - shown as the move's contest description, unless the move
#                 has its own Description in contest_moves.txt
#   Appeal      - base hearts of appeal, unless the move has its own Appeal
#   Flags       - (Acting round, not used yet) tags for the effect's mechanics
# Effects only describe themselves for now: the Acting round will give them
# their mechanics. Section names are used in contest_moves.txt.
